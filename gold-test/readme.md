# Gold Test

This folder contains a simple batch test for the RAG API.

## Files

- `test.sh`: Sends one request per line in `test1.txt`.
- `test1.txt`: Input questions (one question per line).
- `result`: Output file generated by `test.sh`.

## Run

From repo root:

```bash
bash gold-test/test.sh gold-test/test1.txt
```

## Input format

- Put one question per line in `gold-test/test1.txt`.
- Empty lines are ignored.

## Output

- Results are written to `gold-test/result`.
- For each question, output includes:
  - `Q: <question>`
  - pretty-printed JSON response
